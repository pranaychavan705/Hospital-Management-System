# Hospital Management System

A beginner-friendly Hospital Management System developed using Java.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Bill Management
- Medicine Management
- Room Management
- Search and Display Operations

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- Arrays of Objects
- Methods
- Loops
- Switch Statements
- Scanner
- Object Relationships

## Technologies Used

- Java
- Eclipse IDE

## Project Structure

- Patient.java
- Doctor.java
- Appointment.java
- Bill.java
- Medicine.java
- Room.java
- Hospital.java
- HospitalMain.java
