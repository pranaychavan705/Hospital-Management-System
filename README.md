# Hospital Management System

A beginner-friendly Hospital Management System developed using Java and Object-Oriented Programming.

## Features

- Add, display and search patients
- Add, display and search doctors
- Add, display and search appointments
- Add, display and search bills
- Add, display and search medicines
- Add, display and search rooms
- Calculate bill totals
- Calculate medicine total price
- Calculate room rent

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- Methods
- Arrays of Objects
- Object References
- `switch` statements
- Loops
- `Scanner`
- Basic object relationships

## Project Classes

1. `Patient`
2. `Doctor`
3. `Appointment`
4. `Bill`
5. `Medicine`
6. `Room`
7. `Hospital`
8. `HospitalMain`

## Technologies Used

- Java
- Eclipse IDE

## How to Run

1. Download or clone this repository.
2. Open the project in Eclipse.
3. Make sure all classes are inside the `com.hospital` package.
4. Run `HospitalMain.java`.
5. Follow the options shown in the console.
